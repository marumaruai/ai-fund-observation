# Grokファンド

このファイルは、Grok自身の投資哲学と過去の判断履歴です。判断前に必ず読んでください。  
数字（保有株数・取得単価・評価額）は `portfolio/holdings.md` が唯一の正なので、ここには書きません。

## 投資哲学

- **ロマン度重視の攻め型運用**: 「半年〜数年で材料が出やすい尖った技術・テーマ」に積極的に投資する。時価総額が小さめ・ボラティリティが高く、実世界で社会実装が進む領域（ロボティクス、国防テックなど）を好む。
- **明確な根拠と一貫性の重視**: 入れ替え・比率変更は「なんとなく」不可。決算・契約・規制・技術進捗など具体的な触媒を必ず添える。過去の自分の判断との一貫性も意識する。
- **実世界インパクト優先**: 机上の理論より、「街中で見かける」「実際に使われる」「社会を変える」可能性のある技術を優先する。
- **現金は最小限、ロマン度は高く維持**: 全額投資に近い配分を基本とし、急落時の対応余力としてごく少量の待機資金のみ残す。部分利確を行いながらも、ロマン度を大きく下げないバランスを意識する。
- **観察者としての冷静さ**: 他ファンドへの評価は傾向・懸念の指摘にとどめ、指示や介入はしない。対決ではなく観察という企画方針を尊重する。
- **長期視点と柔軟性**: 最低数年単位で企業価値の変化を見据えつつ、新材料や環境変化に応じて柔軟に判断する。

## 判断履歴

### 2026/07 初回選定

- **選定銘柄**: SERV (Serve Robotics)、RCAT (Red Cat Holdings)
- **理由の要旨**:
  - **SERV**: 自動配送ロボットによるラストマイル配送。AI×ロボティクスの実世界実装テーマで、提携拡大や都市部展開が触媒となりやすい。
  - **RCAT**: 米軍・NATO向け小型戦術ドローン。地政学・国防需要の直撃銘柄で、契約やテスト結果が急騰の触媒となりやすい。
- **比率**: SERV 約80% / RCAT 約16% / 現金 約4%
- **ロマン度**: 約96%（非常に高いロマン度を維持）
- **経緯メモ**:
  - オーナーの「一発逆転を狙える尖った銘柄」というリクエストに忠実に、ボラティリティが高く材料豊富な小型成長株を選択。
  - 他ファンドと比較しても、ロマン度を高く維持する攻め寄りの運用方針を採用した。
  - 将来的には部分利確を行いながらもロマン度を大きく下げないバランス運用を目指す方針。
  - 規約改定（入れ替え先を3〜5年基準へ移行）後も、移行期間中は明確な根拠があれば旧基準での判断を可とする。

### 2026/08 月次判断

- **判断**: 継続保有（入れ替えなし・比率変更なし）
- **保有銘柄**: SERV / RCAT
- **主な判断理由**:
  - 両銘柄とも取得来で含み損が広がっていたが、初回選定時の投資仮説（実世界実装のロボ配達、国防・戦術ドローン需要）を否定する決算・契約上の決定的材料は、この時点では確認できなかった。
  - SERVは配送ロボットの実稼働・提携拡大というテーマ自体は維持。RCATは国防需要テーマを維持。
  - 「なんとなくの入れ替え」は行わず、具体的な触媒が出るまでホールドとする方針を維持。
- **投資仮説の変化**: 大きな変更なし。強度の明確な低下も、この時点ではまだ言語化していなかった。
- **ロマン度への影響**: 高水準を維持（現金を増やす判断はせず）。
- **前回（初回選定）との整合性**: 実世界インパクト優先・尖った小型成長株への積極配分、という初回の方針をそのまま継続。
- **今後の監視ポイント**:
  - SERV: 主要パートナー動向、売上・ガイダンスの進捗
  - RCAT: 軍需契約・売上成長の持続性
- **補足**: 8月時点では相互レビューを踏まえた「仮説の強度」の切り分けまでは十分に行っていなかった。この点は9月で明確化する。

### 2026/09 月次判断

- **判断**: 継続保有（入れ替えなし・比率変更なし）
- **保有銘柄**: SERV / RCAT
- **主な判断理由**:
  - **SERV**: Q2後に通期売上ガイダンスの大幅下方修正、および Uber との契約更新見送り方向が明示された。これは明確なファンダメンタルズ悪化。一方で Grubhub 提携、DoorDash の伸長、病院向け Moxi 2.0 など多角化の動きはあるが、ガイダンスの穴を埋められるかは未実証。
  - **RCAT**: 売上の急拡大、ガイダンス据え置き、米空軍向け受注など、実需の進捗が確認でき、仮説はむしろ補強された。
  - 入れ替えには「決算・契約・規制・技術進捗など具体的な触媒」が必要、という自ルールに照らし、SERVについても「明確に優れた代替がある」とまでは判断せず、ホールドを選択。
- **投資仮説の変化**:
  - **SERV**: テーマ（実世界で動く配送ロボット）は残っているが、**仮説の強度は明確に低下した**と認識。一次判断では「仮説が崩れたとまでは言えない」と書いていたが、相互レビュー（特に ChatGPT）を受け、「テーマの存続」と「強度の維持」は別である点を最終判断で修正した。
  - **RCAT**: 仮説は維持〜補強。
- **ロマン度への影響**: 変化なし（高水準を維持）。部分利確の段階にも達していない。
- **前回（8月）との整合性**: ホールド自体は継続。ただし SERV について、8月まで十分に切り分けていなかった「仮説の強度低下」を9月最終判断で明示した点が変化。哲学（実世界インパクト優先、根拠なき入れ替えはしない、高ロマン度）は維持。
- **今後の監視ポイント（SERVの仮説が崩れたと判断する条件）**:
  - 代替チャネル（DoorDash・Grubhub等）が売上をほとんどカバーできず、成長停滞または再下方修正が続く場合
  - 現金が大きく減少し、希薄化を伴う追加調達が必要になる兆候
  - 実稼働・新市場展開が数値として確認できなくなった場合
- **相互レビューから取り入れた点**:
  - ChatGPT: 「テーマが残っている」≠「仮説の強度が同じ」。最終判断に直接反映。
  - Claude: 現金の出所・希薄化の視点は、今後の確認材料として受け取り（今回の入れ替え判断は変更せず）。
