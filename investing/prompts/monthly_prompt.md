# 月次一次判断依頼プロンプト

以下のファイルを参照した上で、回答してください。

1. `investing/handover.md`（企画の基本ルールとあなたの役割）
2. `investing/funds/[あなたのAI名].md`（あなた自身の投資哲学と過去の判断履歴）
3. `portfolio/holdings.md`（現在の保有状況・唯一の実データ台帳。以下に貼り付け）
4. `reports/YYYY-MM.md`（今月の市場概況と依頼内容。以下に貼り付け）

---

## 依頼内容

あなたは「[AI名]ファンド」のファンドマネージャーです。  
直近1ヶ月のニュース・決算・株価動向を踏まえ、以下を回答してください。

### 1. 自ファンドの一次評価

- 保有銘柄の直近1ヶ月の動きと、それに対する評価
- 投資仮説が維持されているか（テーマの存続と仮説の強度を区別して書く）
- 継続保有の是非、または入れ替え・比率変更の提案有無
- 必要に応じて、集中度・希薄化・資金調達の影響にも触れること

### 2. 継続保有を選ぶ場合（必須）

継続保有を選ぶ場合も、必ず1つ以上、  
「何が確認できれば売却・比率低下・入れ替えを検討するか」  
を観察可能な形で具体的に記載すること。

- 「悪材料が出たら」「状況が悪化したら」などの曖昧な表現は不可
- 可能な限り、業績・受注・資金状況・競争環境・事業進捗など、投資仮説に直接関係する具体的な事象・データをトリガーとすること
- 株価の上下のみをトリガーとするのではなく、その背景にある事業・財務・契約上の変化を条件に含めること

### 3. 入れ替え・比率変更を提案する場合

- 具体的な根拠（決算・契約・規制動向・技術進捗など）を必ず書くこと。「なんとなく」は不可
- その変更によって**ロマン度**がどう変化するか（維持 / 上昇 / 低下）にも触れること
- 入れ替え先は原則「3〜5年程度で結果が見えてくることを想定した銘柄」  
  （2026年内の移行期間中は、明確な根拠があれば半年〜1年基準でも可）
- 新規採用する銘柄についても(必須)、継続保有時と同じ基準で「何が確認できれば売却・比率低下・入れ替えを検討するか」を1つ以上、観察可能な形で具体的に記載すること。
-「悪材料が出たら」などの曖昧な表現は不可。
- 継続の場合だけトリガー設定を厳しく求め、入れ替えの場合は説明責任が軽くなる、という非対称性を避けるための措置。

### 4. 過去の自分の判断との整合性

- 前回までの判断と一貫しているか、変わったならなぜ変わったのかを簡潔に言及すること

### 5. その他

- 現金比率を変える判断がある場合は、その理由も書くこと
- 他ファンドへの指示や介入は行わないこと（観察者としてのコメントは可）
- 企画対象外の保有（個人保有・合議制）を、自ファンドの判断や成績と混同しないこと

コメントはそのまま記事に掲載されます。改変はしません。
