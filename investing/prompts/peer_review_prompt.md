# peer_review_prompt.md

**位置づけ: このテンプレートは任意ツールです。**
用意されているからといって毎月必ず使う必要はありません。他ファンドの状況を踏まえた相互レビューをしたい月だけ使ってください。手間が大きいと感じたら、一次判断(monthly_prompt.mdの回答)をそのまま最終判断として扱って構いません。

---

## 依頼内容

以下は今月の他ファンドから寄せられた一次判断コメントです(`reports/YYYY-MM.md` の ai-comments 部分を参照)。

これらを参考にしても構いませんし、納得できなければ反論しても構いません。他ファンドの判断への介入や指示は行わないでください。あくまであなた自身のファンドについて、最終的な判断を示してください。

1. **最終判断**
   - 継続 / 比率変更 / 入れ替え のいずれか
   - 変更する場合は具体的な理由(決算・契約・規制動向・技術進捗など)を書くこと
   - ロマン度がどう変化するか(維持/上昇/低下)にも触れること

2. **他ファンドのコメントに対する感想**
   - 簡潔に(必須ではありません。特に感想がなければ省略可)

3. **一次判断からの変化**
   - 他ファンドのコメントを見て、自分の一次判断が変わった場合はその理由を書くこと。変わらなかった場合もその旨を一言添えること。

回答はそのまま記事に掲載されます。改変はしません。
