# peer_review_prompt.md

**位置づけ: このテンプレートは任意ツールです。**  
用意されているからといって毎月必ず使う必要はありません。他ファンドの状況を踏まえた相互レビューをしたい月だけ使ってください。手間が大きいと感じたら、一次判断（`monthly_prompt.md` の回答）をそのまま最終判断として扱って構いません。

---

## 依頼内容

以下は今月の他ファンドから寄せられた一次判断コメントです（`reports/YYYY-MM.md` の ai-comments 部分を参照）。

これらを参考にしても構いませんし、納得できなければ反論しても構いません。  
他ファンドの判断への介入や指示は行わないでください。あくまであなた自身のファンドについて、最終的な判断を示してください。

### 1. 最終判断

- 継続 / 比率変更 / 入れ替え のいずれか
- 変更する場合は具体的な理由（決算・契約・規制動向・技術進捗など）を書くこと。「なんとなく」は不可
- ロマン度がどう変化するか（維持 / 上昇 / 低下）にも触れること
- 投資仮説の維持・強度の変化にも触れること
- 入れ替えを最終判断する場合は、新規採用する銘柄についても、継続保有時と同じ基準で「何が確認できれば売却・比率低下・入れ替えを検討するか」を1つ以上、観察可能な形で記載すること

### 2. 継続保有を最終判断する場合（必須）

継続保有を最終判断する場合も、  
「何が確認できれば売却・比率低下・入れ替えを検討するか」  
を1つ以上、観察可能な形で具体的に再確認すること。

- 一次判断で設定したトリガーがある場合は、今回の相互レビューや最新情報によって、そのトリガーを変更・維持・追加する必要があるか確認すること
- トリガーを変更・追加した場合は、その理由を一行で添えること
- 「悪材料が出たら」「状況が悪化したら」などの曖昧な表現は不可
- 可能な限り、業績・受注・資金状況・競争環境・事業進捗など、投資仮説に直接関係する具体的な事象・データをトリガーとすること
- 株価の上下のみをトリガーとするのではなく、その背景にある事業・財務・契約上の変化を条件に含めること

### 3. 他ファンドのコメントに対する感想

- 簡潔に（必須ではありません。特に感想がなければ省略可）
- 他ファンドへの指示・介入は行わないこと

### 4. 一次判断からの変化

- 他ファンドのコメントを見て、自分の一次判断が変わった場合はその理由を書くこと
- 変わらなかった場合もその旨を一言添えること

回答はそのまま記事に掲載されます。改変はしません。

## 最終判断後の作業（忘れず）

最終判断が終わったら、自分の `investing/funds/[あなたのAI名].md` に今回の判断履歴を追記すること。  
実データ（株数・評価額など）は書かず、判断内容・理由・仮説の変化・監視ポイント・トリガーに留めること。
