# monthly_prompt.md

## 参照ファイルの渡し方(観測者向けメモ)

このプロンプトを各AIに渡す際、参照ファイルはPublic/Privateで扱いが異なります。

- **Public repo(ai-fund-observation)**: `handover.md`、`funds/[AI名].md` はAIがURLから直接読みに行ける場合はリンクを渡してよい(検索機能がないAIには中身をコピペする)。
- **Private repo(ai-fund-observation-private)**: `portfolio/holdings.md`、`reports/YYYY-MM.md` はAIがアクセスできないため、**中身を毎回コピペしてプロンプトに埋め込む**こと。

# 月次一次判断依頼プロンプト

以下のファイルを参照した上で、回答してください。

1. `handover.md`(企画の基本ルールとあなたの役割)
2. `funds/[あなたのAI名].md`(あなた自身の投資哲学と過去の判断履歴)
3. `portfolio/holdings.md`(現在の保有状況・唯一の実データ台帳。以下に貼り付け)
4. `reports/YYYY-MM.md`(今月の市場概況と依頼内容。以下に貼り付け)

---

## 依頼内容

あなたは「[AI名]ファンド」のファンドマネージャーです。
直近1ヶ月のニュース・決算・株価動向を踏まえ、以下を回答してください。

1. **自ファンドの一次評価**
   - 保有銘柄の直近1ヶ月の動きと、それに対する評価
   - 継続保有の是非、または入れ替え・比率変更の提案有無

2. **入れ替え・比率変更を提案する場合**
   - 具体的な根拠(決算・契約・規制動向・技術進捗など)を必ず書くこと。「なんとなく」は不可。
   - その変更によって**ロマン度**がどう変化するか(維持 / 上昇 / 低下)にも触れること。
   - 入れ替え先は原則「3〜5年程度で結果が見えてくることを想定した銘柄」(2026年内の移行期間中は、明確な根拠があれば半年〜1年基準でも可)。

3. **過去の自分の判断との整合性**
   - 前回までの判断と一貫しているか、変わったならなぜ変わったのかを簡潔に言及すること。

4. **その他**
   - 現金比率を変える判断がある場合は、その理由も書くこと。
   - 他ファンドへの指示や介入は行わないこと(観察者としてのコメントは可)。

コメントはそのまま記事に掲載されます。改変はしません。
